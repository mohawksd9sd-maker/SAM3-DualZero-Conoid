# Gauge Unification — Geometric KK Floor

**Updated:** August 2026 — see also the Priority 4 lock note `12_Unification_Floor_Demotion.md`.

## 1. Setup

- Laplace spectrum on the internal conoid geometry supplies Kaluza–Klein thresholds.
- Thresholds enter the renormalization-group evolution of the gauge couplings.
- Analysis used a large tower (order 100+ modes), two-loop SM running, and rough scheme-matching estimates.

## 2. Result

- Correction to the inverse couplings: \(\Delta\alpha^{-1}\sim O(10)\) (correct order of magnitude).
- Residual relative mismatch after the tower: approximately **7%**.
- This is a **geometric floor under present assumptions**, not a statistical error bar.

**Percent-level unification is not achieved and is not claimed.**

## 3. Locked public statement

> The right-conoid geometry produces KK thresholds of the correct order (\(\Delta\alpha^{-1}\sim O(10)\)). After two-loop running the residual relative mismatch is approximately 7%. Percent-level unification is not claimed.

## 4. What would be required to improve the floor

New geometric input, for example:
- a derived intermediate scale from 2I breaking,
- a corrected assignment of which Laplace eigenmodes transform as full SM adjoints,
- or completed Seeley–DeWitt threshold contributions on the warped product.

Simply taking a longer tower without new geometry does not remove the ~7% residual.

Priority 4 locked as clean demotion. See `12_Unification_Floor_Demotion.md`.
