## 3. $\operatorname{Reg}_2$ — single locked definition

**On sequences (primary, spectral mode towers):**

$$
\operatorname{Reg}_2(a)_n
:=
\frac{a_{2n}+a_{2n+1}}{2}.
$$

**On continuum test functions (secondary, same idea):**

$$
\operatorname{Reg}_2(f)(\lambda)
:=
\lim_{\delta\to 0^+}
\frac{f(\lambda+\delta)+f(\lambda-\delta)}{2}
$$

when a continuum symbol is being dual-averaged. These are **one principle** (symmetric dual average), two domains. Older files that wrote only one without the other are not contradictory if both are read as dual averaging; this note locks both.

**Physical reading:** odd / graded sectors cancel under dual average; even / physical sectors survive. That is the information-conservation move relative to a hard UV wall.
